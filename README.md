# NexusTask Pro 📝

A modern Full Stack Task Management Web Application that helps users organize tasks, manage reminders, and improve productivity through an intuitive and responsive interface.

## 🚀 Features

- ✅ Create, update, and delete tasks
- 📅 Calendar View
- 📋 Kanban Board
- 🔔 Reminder & Notification System
- ⏳ Pomodoro Timer
- 📊 Analytics Dashboard
- 🏷️ Categories and Tags
- ⭐ Priority & Status Management
- 🔄 Recurring Tasks
- ✔️ Subtasks Support
- 📱 Responsive UI

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript (ES6+)
- CSS3
- Vite

### Backend
- Node.js
- Express.js
